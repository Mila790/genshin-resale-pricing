# Genshin Impact Resale Pricing Analysis

> 基于闲鱼 819 条真实挂牌数据的多元线性回归分析：二手原神周边的价格由哪些因素决定？

## 研究问题

在二手交易平台闲鱼上，原神周边的挂牌价格由哪些因素决定？本项目检验六个候选因素：品类、角色、稀有度、成色、卖家地区、需求热度。

## 核心结论

- **训练 R²=0.86，测试 R²=0.82，5 折交叉验证 R²=0.84±0.02**
- **品类主导**（β=1.58，p<0.001）：手办比吧唧贵 30 倍
- **稀有度显著**（隐藏款 β=0.13，p<0.001）
- **三个反直觉发现**（p>0.05，即不显著）：
  1. 成色对官谷二手价无影响（买家不为"全新未拆"标签多付钱）
  2. 地区价差已被全国统一市场抹平
  3. 需求热度（"X 人想要"）与挂牌价无关——热度决定卖多快，不决定卖多贵

## 数据

- **来源**：闲鱼网页版（goofish.com）公开挂牌
- **抓取**：6 个关键词 × 10 页 = 1798 条原始记录
- **清洗漏斗**：1798 → 1495（去重/剔噪音）→ 1141（删无角色）→ 819（分层抽样）
- **时间**：2026 年 11 月

## 方法说明

- 因变量取 ln(价格)（价格右偏）
- 80/20 训练/测试留出，5 折交叉验证
- 系数显著性用 t 检验（p<0.05 标 *）
- 需求热度缺失记 0，并额外加 `需求热度缺失` 标记列，区分"真 0"和"未知"

## 局限

- 挂牌价 ≠ 成交价
- 需求热度字段缺失约 47%
- 未控制时间维度和已成交数据
